Knuth-Plass optimal wrap — like wrap_with but choosing break points to minimise whole-paragraph demerit (badness + fitness-class evenness) rather than filling each line greedily. Same measure contract, same WrappedLine output, so it is a drop-in replacement for wrap_with. See the “Knuth-Plass optimal line breaking” notes above for when it pays off. Each atom is measured as raw source at style; callers whose drawn representation differs from the raw bytes should use wrap_optimal_with.
