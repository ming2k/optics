# ADR-0053: Shader embedding — C23 #embed with generated-header fallback

- Status: Accepted
- Date: 2026-08-08
- Scope: build system + every translation unit that bakes SPIR-V
  (flux canvas/effect/scene, flux tests, flux + showcase examples).

## Context

Shaders are compiled to SPIR-V at build time by glslangValidator and
baked into binaries with C23 `#embed` + `--embed-dir`. `#embed` requires
clang ≥ 19 or GCC ≥ 15: MSVC `cl` has no `#embed` and rejects unknown
options like `--embed-dir`, and Apple Clang (Xcode 16, LLVM 17 base)
lags upstream. Windows/macOS support needs the tree to compile on those
toolchains without giving up the standard mechanism everywhere else.

## Decision

1. **Dual path per TU.** Each embedding source computes a file-local
   `*_SHADERS_EMBED` switch with `__has_embed(...)` for every shader it
   uses: the `#if` branch keeps `#embed`, the `#else` branch
   `#include`s a header generated by `tools/spv2h.py` that defines the
   same `alignas(uint32_t) static const unsigned char <name>[]` arrays,
   byte-identical (the script asserts 4-byte alignment and the SPIR-V
   magic). Call sites never change.
2. **Meson always generates the headers** (cheap python custom_targets)
   so the fallback works without reconfiguration; `--embed-dir` is added
   only via `cc.get_supported_arguments`.
3. **No meson option.** Selection is automatic (compiler capability).
   `FLUX_SHADER_NO_EMBED` forces the fallback so it stays compile-tested
   on `#embed`-capable hosts in CI.
4. The same idiom applies to tests and examples; generated test-shader
   headers ride `test_helpers_dep`'s `sources` so consuming tests need
   no per-target wiring.

## Alternatives Considered

- **Always use generated headers (drop #embed).** Rejected: regresses
  to the pre-C23 mechanism on toolchains that support the standard one;
  the dual path is preprocessor-only and both branches are compile-gated
  in CI.
- **Runtime .spv file loading.** Rejected: adds install-layout coupling
  and failure modes for zero benefit; baked-in shaders are a deliberate
  property of the examples and library.
- **xxd-style checked-in arrays.** Rejected: generated-at-build keeps
  the single source of truth (the .spv) and cannot go stale in git.

## Consequences

- MSVC cl and Apple Clang build the full tree unmodified.
- Adding a shader means one custom_target pair (spv + header); the C
  side follows the five-line idiom shown in
  `libs/flux/src/canvas/renderer.c`.
- Both branches must stay byte-identical; `spv2h.py` asserts alignment
  and magic, and `FLUX_SHADER_NO_EMBED` CI builds keep the fallback
  exercised.
