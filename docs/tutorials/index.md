# Tutorials

Step-by-step lessons taking you from a clean checkout to building and running your first 2D and 3D graphics applications with Optics. Start here if you are new to the project.

---

## Learning Path

| Tutorial | What You Will Do | Key Concepts Learned |
| :--- | :--- | :--- |
| **[01. Getting Started](01-getting-started.md)** | Install dependencies, configure the Meson build, run tests, and execute your first example. | Toolchain, build configuration, test suite |
| **[02. Your First 2D Application](02-first-2d-app.md)** | Build a 2D vector canvas application from scratch (`hello_canvas.c`). | `flux_device`, `flux_surface`, `flux_canvas`, per-frame recording |
| **[03. Your First 3D Application](03-first-3d-app.md)** | Render a lit 3D cube with depth testing from scratch (`scene_cube.c`). | `flux_camera`, `flux_mesh`, `flux_material`, depth pass |

For focused tasks or specific problem recipes, consult the [How-To Guides](../how-to/index.md).
